# 大模型相关面试题

## 什么是大模型
现在的大模型都是基于Transformer架构的，词元预测模型。

就像拥有各行各业丰富经验的专家，给它一个开头就可以根据上下文逐字逐句的生成文本内容。

什么是大模型，这个要讲的东西就多了，以chatgpt为例，讲一下它的发展过程：

gpt是基于Transformer架构演化而来的，transformer架构是一种基于自注意力机制的模型，它本身翻译器通过编码器和解码器来实现对文本的预测翻译。

举个例子我喜欢动物，我养了xx，大模型的注意力机制。会讲每次token转换为qkv

q表示当前token与整个序列的注意力权重， 如养了这个词表示是在整个句子的含义是我要养什么样动物
k表示当前token的特征向量，如养了表示动词，要接一个动物名词
v表示当前token的语义信息，通过计算后的完整含义养了表示照料、喂养、拥有宠物

我们通过v这个语义数据去词库对比就能拿到很多相关联的词元
然后每个词元都进行归一化处理，得到一个0-1的数值。

随机从这些词元中选择一个，作为当前token的预测结果。

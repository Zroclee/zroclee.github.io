# 前端转JAVA速通分享-总览

AI时代下，编码成本极低，尤其是对前端开发的冲击。很多公司要求前端转全栈。
前端转JAVA实属无奈，只是为了能继续在牌桌上玩。

如何学习？
具备编程基础
将java和js相通的概念对比
不一致的部分深入学习

学习方式：找相同和找不同
结合AI快速掌握java的基本概念和语法。


背景：我是一个前端开发，正在转型全栈开发，需要学习java补全后端开发能力。
拥有能力：我多年前端开发经验，精通javascript、Typescript、html、css，熟悉Vue框架，Vite、Webpack等构建工具。
目标：请根据我掌握的知识，通过对比的方式，将js与java概念一致的知识进行对比展示，java独有的且比较重要的知识进行重点标记，帮助我快速掌握java。
任务：现在开始第三章的学习：学习面向对象编程中的抽象类和接口类、静态类和枚举类。
